## Installation et exécution locale

Suivez ces étapes pour exécuter le projet en local :

### Prérequis

- [Node.js](https://nodejs.org/) installé
- Un fichier `.env` ( 📕 suivez le `.env.example` )
  
### Étapes

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/Aminebneji/ReactCv2k25.git
   cd ReactCv2k25
   ```

2. Installez les dépendances :
   ```bash
   npm install
   ```

3. Lancez le projet :
   ```bash
   npm start
   ```

Le portfolio sera accessible sur `http://localhost:3000`.
